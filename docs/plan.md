### Следующий: пакет 17, eval исправлений

Цель — мерить качество исправлений до того, как менять промпты (пакет 12) и модели. `cyrano-eval` из пакета 13 получает команду для Fix, Explain и диалога; кейсы из `evals/cases.json` переходят на него, проверки — явные ошибки, а не нюансы и не точный эталон. ≥ 30 кейсов, среди них — язык: CONTEXT на испанском, а в pop-up пользователь выбрал Russian — результат на русском: Fix берёт язык из pop-up, а не из CONTEXT. Прогнать на трёх моделях, в том числе `gpt-6.1-terra`: её ещё не проверяли. После этого `evals/cloud-runner` удаляем.

### Когда готовы скриншоты: пакет 18, контекст на живых окнах

Пользователь собирает 5–10 скриншотов по ситуациям из 04 §5, пока идут другие пакеты: окно снято так же, как его снимает Cyrano (⇧⌘4, Space, клик по окну с ⌥ — без тени), черновик набран в поле ввода; скриншот и текст черновика — в `evals/private/context/`. Дальше вместе пишем целевой контекст, прогоняем промпт из пакета 13 и сравниваем с синтетикой: что модель путает на живых окнах и чего нет в шаблонах — добавляем в синтетику, промпт доводим. Если промпт меняется — релиз.

## Что работает

- Хоткей ⌥⌘G (настраивается) → текст из выделения или всего поля (Accessibility или ⌘C явного выделения, без ⌘A и без чтения со скриншота — 02 C2) → панель рядом с полем с открытым Context → Check у поля диалога → потоковая проверка → карточка Version 1 с подсветкой и пояснениями.
- Контекст со скриншота (02 C6): если текст взят из окна приложения, модель чтения контекста (по умолчанию `gpt-6-luna`) описывает по скриншоту окна беседу — с кем, на каком языке, о чём, формат (ответ, напоминание, новая тема), стиль, формальность — и заполняет Context строками, без копирования сообщений; язык беседы ставит в pop-up языка, если пользователь его не выбрал. Check ждёт до 20 с; статус чтения — у заголовка Context: секунды, Skip, «No conversation found», таймаут или ошибка с Try Again; Skip и ввод в Context прерывают вызов. Переключатель в Settings → General и в онбординге. Eval — `cyrano-eval context`: 13 синтетических окон в `evals/context/` и 6 настоящих в `evals/private/context/` (вне git), 13/13 и 6/6 на Luna (04 §5).
- «Text to check» правится до первой проверки; если текст не забран (рабочий стол, Finder), панель открывается с пустой карточкой. Check Text… и Check Clipboard открывают ту же панель, отдельного окна нет.
- Панель высотой по содержимому до 70% высоты экрана, дальше прокручивается только лента; растёт вниз, верхний край на месте.
- Шапка: тип, тон, уровень, язык результата; смена перепроверяет последнюю версию. Тип, тон и уровень запоминаются для приложения, язык — нет: панель открывается с «Auto». Запомненное видно в Settings → Style → Per-app defaults, удаление строки возвращает Message · Neutral · Fluency.
- Подсказки TipKit в панели: Context, 📷, поле диалога — по одной, пока их не закроют или не выполнят.
- Context — только ввод: поле над лентой, до первой проверки открыто, при запросе сворачивается; клик по строке раскрывает.
- Одна кнопка у поля диалога: Check до первой проверки и когда контекст изменился, а поле пустое (перепроверка); иначе Send — сообщение уходит вместе с текущим контекстом. Поле диалога появляется после первой проверки. Индикатор — одно число токенов.
- Изображения в Context: 📷 снимает окно исходного приложения (перед первым запросом Screen Recording — строка пояснения), ⌘V вставляет картинку или файл изображения в любой раскладке и при любом фокусе в панели, файлы и картинки можно перетащить на панель. Миниатюры с ✕; после 10 изображений подпись предупреждает о скорости и расходе. Клик или пробел на миниатюре — Quick Look. Картинки уходят в первом сообщении каждого запроса Fix.
- Диалог: вопрос → ответ пузырём, просьба → новая карточка.
- Карточка: Copy (основная у последней), список правок с причинами, отклонение правки локально.
- Словарь «Never change» (02 M11): правый клик по выделению в карточке — Never Change “…” или Remove “…” from Dictionary; правый клик по строке изменения последней карточки — Never Change для каждого изменённого слова: правка отклоняется, слово добавляется одним действием. Строка статуса «“…” added to Dictionary.» с Undo. Найденные в тексте термины идут в первом сообщении Fix строкой `Keep these words exactly as written: …` со следующего запроса. Файл — `~/Library/Application Support/Cyrano/dictionary.json`.
- Ошибки: нет входа (кнопка входа и повтор), сеть, лимит, «Copy Original».
- Модели: `gpt-6.1-sol`, `gpt-6.1-terra`, `gpt-6-luna`; выбор отдельно для чтения контекста (по умолчанию Luna), проверки и диалога (Sol), пояснений (Sol). Классификатор идёт на модель проверки.
- Онбординг одним окном: вход, Accessibility, контекст из окна (переключатель и Screen Recording), хоткей. Settings: General (меню, Launch at login, чтение контекста, модели, хоткей, разрешения), Style (custom instructions, per-app defaults), Dictionary (поиск, добавление, правка двойным кликом, удаление, импорт и экспорт), Account.
- Menu bar: Check Text…, Check Clipboard, аккаунт, About, Settings, Quit. Своя иконка приложения.
