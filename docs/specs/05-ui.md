# 05. UI

Статус: **черновик, сверен с Apple HIG** 2026-10-27 (§8). Сценарии — [03](03-mvp-scope.md), технические решения — [02](02-tech-decisions.md), wireframes — [../wireframes](../wireframes/README.md).

## Принципы

- **Функциональность, а не эффекты.** Никаких анимаций, кроме системных. Никаких всплывающих подсказок поверх чужих приложений.
- **Одно сочетание.** Глобальный хоткей открывает панель; внутри — кнопки, Tab и системные клавиши, своих сочетаний нет, чтобы ничего не нужно было запоминать (02 T6).
- **Чужое окно не теряет фокус ввода, пока не нужно.** Панель — `NSPanel` (`.nonactivatingPanel`). Фокус она забирает только при клике в поле диалога или Context.
- **Системный вид.** SwiftUI + стандартные контролы, семантические системные цвета и шрифты, светлая и тёмная темы.
- **Цвет — не единственный носитель смысла.** Каждое цветовое различие продублировано формой: зачёркивание, подчёркивание, значок, заголовок группы.
- **Ориентир — Writing Tools в macOS.** Системная функция Apple решает похожую задачу (proofread поверх любого приложения, поле «Describe your change»), поэтому в спорных местах повторяем её поведение.
- **Текст пользователя не теряется.** При любой ошибке исходник остаётся доступен для копирования.

## 1. Онбординг

Одно окно с тремя секциями (`Form`, `.grouped`), все видны сразу, без пошагового мастера: так проще вернуться к любому пункту, а шагов всего три. Внизу кнопка «Done». Окно открывается при первом запуске и при каждом запуске, пока нет входа или Accessibility.

```
┌─ Cyrano ───────────────────────────────────────────┐
│ 1. Sign in                                         │
│   Cyrano uses your ChatGPT Plus or Pro plan        │
│   to check your messages.                          │
│   [ Continue with ChatGPT ]                        │
│   Your text is sent to OpenAI only when you run    │
│   a check. It is not stored.                       │
│ 2. Accessibility                                   │
│   Cyrano reads the text in the field you're …      │
│   Accessibility          [Open System Settings…]   │
│ 3. Shortcut                                        │
│   Check text                         [ ⌥⌘G ]       │
│   Show in menu bar                        [on]     │
│                                          [Done]    │
└────────────────────────────────────────────────────┘
```

1. **Sign in.** Кнопка «Continue with ChatGPT» по гайдлайнам OpenAI → системный браузер. Пока ждём колбэк: «Waiting for the browser…» [Cancel]. Удачный вход: «Signed in as name@…». Ошибки:
   - отказ в браузере → «Sign-in was cancelled.» [Try Again];
   - нет `chatgpt.tokens.use.direct` → «Your plan doesn't allow apps to use it. Plus or Pro is required.»;
   - сеть / таймаут 5 мин → «Couldn't reach OpenAI.» [Try Again].
2. **Accessibility.** Одно предложение о том, зачем: «Cyrano reads the text in the field you're typing in, so you don't have to copy it.» Кнопка «Open System Settings…». Статус обновляется сам (опрос `AXIsProcessTrusted` раз в секунду) → «✓ Granted». Без разрешения можно нажать Done: работает режим через буфер обмена.
3. **Shortcut.** Поле записи хоткея (по умолчанию ⌥⌘G), подсказка «Select text or put the cursor in a text field, then press the shortcut.» и переключатель «Show in menu bar» (включён). Остальное объясняем контекстными подсказками в самой панели при первом использовании (TipKit): Context, 📷, диалог.

Screen Recording в онбординге не спрашиваем — только при первом нажатии 📷.

## 2. Панель проверки

### 2.1 Положение и размер

- Ширина 520 pt, высота по содержимому, максимум 70% высоты экрана, дальше прокрутка.
- Позиция: под полем ввода (bounds из AX), если поле видно и под ним хватает места; иначе над полем; иначе по центру экрана, где курсор.
- У панели стандартная строка заголовка с коротким заголовком-существительным **«Proofreading»** и кнопкой закрытия; кнопок свернуть/развернуть нет. Перетаскивается за заголовок. Позиция не запоминается.
- Закрывается по Esc и по кнопке ✕. При клике в другое место **не закрывается** — можно переключиться в чат, скопировать контекст и вернуться.

### 2.3 Заголовок

- **Источник:** имя приложения, из которого взят текст («Slack»). Для текста, введённого или вставленного в панели, — «Manual».
- **Тип контекста:** Message / Email / Docs. **Тон:** Neutral / Casual / Friendly / Professional / Concise. **Уровень:** Errors only / Fluency / Rewrite. Это стандартные pop-up buttons (SwiftUI `Picker` со стилем `.menu`): название значения и двойной шеврон в квадрате акцентного цвета. Смена любого значения перепроверяет последнюю версию с новыми настройками и добавляет в ленту новую карточку. Значения запоминаются для приложения (bundle id).
- **Язык результата** — pop-up справа в шапке со значком глобуса: «Same as Text (English detected)» (по умолчанию, в кнопке — «Auto»), English (US), English (UK), Russian, German, Spanish, «More Languages…». Выбор перепроверяет последнюю версию и добавляет новую карточку; если язык отличается от языка текста, модель переводит. Значение запоминается для приложения вместе с типом и тоном.
- ✕ закрывает панель.

### 2.3a Контекст

Контекст — то, на что пользователь отвечает, — стоит **над** текстом: так панель читается сверху вниз, как переписка. Секция занимает одну строку и не раздувает панель. Context — только ввод: текст, картинки, 📷. Своих кнопок проверки в нём нет; проверку запускает кнопка действия у поля диалога (§2.7).

- **Свёрнуто, есть содержимое:** `▸ Context` + первая строка текста контекста (обрезается многоточием) + миниатюры изображений 30×22 + кнопка 📷. Клик по строке раскрывает.
- **До первой проверки:** раскрыто; в ленте карточка «Text to check» (§2.4). Курсор — в поле контекста, если текст забран, иначе в «Text to check». Смена типа, тона и уровня проверку не запускает. После Check секция сворачивается.
- **Чтение контекста** (02 C6): если текст взят из окна приложения, Cyrano сразу снимает это окно и заполняет поле: кто участвует в переписке и на какое сообщение пользователь отвечает. Пока идёт чтение, в поле приглушённая строка «Reading context from the window…» с маленьким индикатором, а Check неактивна; обычно это несколько секунд, максимум 10. Если пользователь начал печатать в поле, чтение останавливается, и его текст остаётся. Если на скриншоте нет переписки или чтение не удалось, поле остаётся пустым, без сообщения об ошибке. Скриншот не добавляется миниатюрой: в контекст уходит только текст.
- **Свёрнуто, пусто:** `▸ Context` + приглушённая подсказка «Add what you're replying to» + 📷.
- **Раскрыто:** поле на 3 строки (растягивается до 8, потом прокрутка), под ним миниатюры 56×38 с ✕ и подпись «or paste ⌘V / drop images · 2 images». Текст редактируется прямо в поле: можно дописать руками что угодно.

```
├──────────────────────────────────────────────────────────────┤
│ ▾ Context                                                  📷 │
│ ┌──────────────────────────────────────────────────────────┐ │
│ │ Ravi: Hi Alex, when you were off last week, I noticed    │ │
│ │ that some PRs weren't tagged…                            │ │
│ │                                                          │ │
│ └──────────────────────────────────────────────────────────┘ │
│ [▭]ˣ [▭]ˣ  or paste ⌘V / drop images · 2 images              │
├──────────────────────────────────────────────────────────────┤
```

- **Миниатюры:** клик выбирает миниатюру и открывает Quick Look — крупный просмотр; пробел на выбранной миниатюре открывает и закрывает его. Так можно отличить похожие скриншоты перед тем, как удалить лишний.
- **Изображения:** 📷 снимает активное окно исходного приложения; ещё можно вставить ⌘V или перетащить файл на панель. Жёсткого предела нет; после 10 изображений подпись предупреждает, что проверка станет медленнее и дороже. Первое нажатие 📷 — системный запрос Screen Recording, перед ним одна строка: «To see the conversation you're replying to, Cyrano needs to capture this window once.» Для вставки и перетаскивания разрешение не нужно. Если текст введён или вставлен в панели (рабочий стол, Check Text…, Check Clipboard), исходного окна нет, и 📷 не показывается; вставка и перетаскивание работают. ⌘V с картинкой в буфере добавляет её в контекст при любом фокусе в панели и в любой раскладке.
- Изменение контекста (текст, добавление или удаление изображения) само проверку не перезапускает: кнопка у поля диалога снова становится **Check**, если поле пустое, а Send отправляет сообщение вместе с новым контекстом (§2.7).
- Свернуть обратно — клик по `▾ Context` или Esc, когда фокус в поле контекста.

### 2.4 Лента: чат с карточками версий

Панель — это чат. Каждый вариант текста от модели — **карточка**, сообщения пользователя и ответы на вопросы — пузыри между карточками. Отдельной навигации по версиям нет: история — это прокрутка ленты.

- **«Text to check»** — карточка до первой проверки. Её текст можно править: поправить забранное или ввести текст с нуля. Если текст не забран (рабочий стол, Finder, Check Text…), карточка пустая, с курсором и подсказкой «Select text in any app and press ⌥⌘G, or type or paste it here». После Check карточка становится неизменяемой, а следующей появляется Version 1.
- **Порядок:** Version 1 (первая проверка) → сообщение → Version 2 → … Новое появляется внизу, лента прокручивается к нему. Лента растёт вместе с панелью до 70% высоты экрана, дальше прокручивается только она; заголовок, Context и поле ввода остаются на месте.
- **Сообщение пользователя** — пузырь справа (accent color), показывается целиком, переносится по ширине. **Ответ на вопрос** — пузырь слева, без новой карточки.
- **Своя версия** («check my version: …») — сообщение целиком, а исправленный вариант — следующая карточка.

**Карточка версии**
- Шапка: «Version N».
- **Действие — внутри карточки**, в строке со сводкой справа: **Copy**. Так всегда видно, какой именно вариант копируется. У последней карточки Copy — основная кнопка (accent color), у предыдущих — обычная. Copy кладёт вариант карточки в буфер обмена, панель остаётся открытой; вставляет пользователь сам (02 C3).
- Текст с diff относительно предыдущей карточки (у Version 1 — относительно исходника), шрифт системный 14 pt, текст можно выделять и копировать. Удалённое зачёркнуто и приглушено (`secondaryLabelColor`); добавленное — сплошное подчёркивание и подложка `systemGreen` 20%; правки `style` — пунктирное подчёркивание и подложка `systemBlue` 15%. Цвет дублируется типом линии.
- Под текстом одна строка-сводка «▸ 5 fixes · 1 style suggestion» (или «▸ 1 change», «✓ No changes needed»). Клик раскрывает список изменений.
- Список изменений: значок (● ошибка, ◇ стиль), справа в столбик `было → стало` (моноширинный, длинные правки переносятся) и причина; справа ✕ «отклонить». Отклонение создаёт новую карточку локально, без вызова модели. Пока Explain не пришёл, сводка — «Explaining…»; если упал — правки без причин.
- Карточку нельзя редактировать: изменения просим сообщением.
- VoiceOver читает правку как «noted, replaced with noticed, error» / «… style suggestion»; карточка объявляется как «Version 2, 1 change».

**Словарь из карточки**
- Выделить слово или фразу в тексте карточки версии → контекстное меню (правый клик или ⌃-клик) → **Never Change “…”** первым пунктом, над системными. Пробелы, знаки препинания и кавычки по краям выделения отбрасываются; выделение через перенос строки термином не считается. Для слова из словаря меню показывает «Remove “…” from Dictionary». Внизу панели строка «“Bitbucket” added to Dictionary.» (или «“…” removed from Dictionary.») с Undo. Учитывается со следующей проверки.
- Тот же пункт в контекстном меню строки изменения последней карточки («Never Change “k8s”»): отклоняет правку и добавляет прежнее слово одним действием. Соседние правки склеиваются (`kibana, take → Kibana. Take`, §2 в 04), поэтому пункт свой у каждого прежнего слова, которого нет в новом тексте как есть: «Never Change “kibana”», «Never Change “take”». Если правка только вставила слова, пунктов нет. Меню открывается по всей строке. Undo убирает термин из словаря; отклонённая правка остаётся карточкой в ленте.

### 2.7 Нижняя часть

Поле диалога на всю ширину, под ним одна строка статуса: индикатор токенов и короткие сообщения («“Bitbucket” added to Dictionary.» с Undo, «Copied.»). Кнопок здесь нет: Copy живёт в карточках. Подписи и статус не переносятся — длинный статус обрезается многоточием, полный текст в подсказке.

- **Индикатор токенов** `1.2k tokens`: сумма `usage` всех вызовов за панель, включая чтение контекста; одно число, без разбивки. Если лимит подписки исчерпан — красный «Plan limit reached».
- **Поле диалога** появляется после первой проверки: до неё говорить не о чем, а недоступное поле с подсказкой путает. Многострочное, фиксированной высоты в 2 строки, дальше прокручивается внутри: короткие реплики помещаются, панель не прыгает. ↩ — перенос строки. Плейсхолдер «Ask or tell what to change… (any language)». Новое сообщение применяется к последней версии.
- **Кнопка действия** справа от поля — одна на панель, другой кнопки проверки нет. Это обычная кнопка с текстом; вид не меняется, меняется только надпись:

  | Состояние | Надпись | Что делает |
  |---|---|---|
  | До первой проверки | **Check** | первая проверка с контекстом; поля диалога ещё нет, неактивна, пока текст пуст или идёт чтение контекста |
  | После, контекст не менялся | **Send** | отправляет сообщение; при пустом поле неактивна |
  | После, контекст изменился, поле пустое | **Check** | перепроверяет последнюю версию с новым контекстом |
  | После, контекст изменился, в поле сообщение | **Send** | отправляет сообщение вместе с новым контекстом |

  Пока идёт проверка, кнопка неактивна. «Контекст изменился» — текст или изображения отличаются от отправленных в последнем запросе.

### 2.8 Состояния панели

| Состояние | Что видно |
|---|---|
| Захват | «Reading text…» (обычно мгновенно, не мигает, если < 150 мс) |
| Пустой текст | карточка «Text to check» пустая и редактируемая, курсор в ней (§2.4) |
| Проверка | исходный текст приглушён, сверху тонкая полоса прогресса; текст версии появляется потоком |
| Результат | см. макет |
| Ход диалога | поле ввода заблокировано, в ленте «…» |
| Ошибка сети / таймаут | «Couldn't reach OpenAI.» [Try Again] [Copy Original] |
| Лимит | «Your ChatGPT plan limit for this app is reached.» [Copy Original]; ссылка на настройки лимита |
| Не вошёл / токен отозван | «Sign in to ChatGPT to check text.» [Continue with ChatGPT] |
| Нет Accessibility | текст берётся только ⌘C из выделения или вводится в панели; в заголовке значок ⚠︎ с подсказкой «Grant Accessibility to read text directly» |

### 2.9 Клавиатура

Своё сочетание одно — **Check text**, ⌥⌘G по умолчанию, работает глобально и меняется в онбординге и Settings → General → Shortcut (02 T6). Внутри панели своих сочетаний нет; действия — кнопками.

Системные клавиши: ↩ — перенос строки в полях, Esc — закрыть панель (если фокус в поле — сначала убрать фокус), Tab — переход между элементами, ⌘C — копировать выделенное, ⌘V — вставить текст или картинку (§2.3a), ⌃-клик / правый клик по выделению — контекстное меню с Never Change.

## 3. Check Text… и Check Clipboard

Отдельного окна нет. **Check Text…** открывает ту же панель по центру экрана с пустой карточкой «Text to check» (§2.4). **Check Clipboard** открывает её с текстом из буфера обмена; если в буфере нет текста — с пустой карточкой. Источник — «Manual», чтения контекста нет.

## 4. Меню в строке меню

Иконка — SF Symbol `text.badge.checkmark` (шаблонная, 24 pt строка меню). По клику — меню, не popover. Показ иконки — выбор пользователя («Show in menu bar» в онбординге и General). Если иконка скрыта, повторный запуск приложения из Finder или Spotlight открывает Settings — это единственная точка входа кроме хоткея.

```
Check Text…
Check Clipboard
─────────────────────────────
Model: gpt-6.1-sol            ▸   (sol / luna)
Signed in as name@…
─────────────────────────────
About Cyrano
Settings…                    ⌘,
Quit Cyrano                 ⌘Q
```

Если не вошёл — вместо строки аккаунта «Sign In with ChatGPT…». Если нет Accessibility — пункт «Grant Accessibility…». Многоточие только у пунктов, которые открывают окно или требуют ввода.

## 5. Settings

Окно со стандартной неизменяемой панелью инструментов из пяти вкладок — General, Style, Dictionary, Prompts, Account (значок + подпись); содержимое — SwiftUI `Form` со стилем `.grouped`: скруглённые секции, подпись слева, контрол справа, строки 40–44 pt, переключатели — `Toggle` в виде switch, выпадающие списки — стандартные pop-up buttons регулярного размера; заголовок окна — имя активной вкладки; открывается последняя использованная вкладка; кнопки свернуть/развернуть неактивны. Настроек минимум: всё, что относится к текущей проверке (тип, тон, уровень, контекст), меняется в самой панели.

**General**
- Model: `gpt-6.1-sol` — Best quality · `gpt-6-luna` — Faster.
- Show in menu bar.
- Read context from the window: включено по умолчанию. При вызове из приложения Cyrano снимает окно и заполняет Context (02 C6). Подпись: «A screenshot of the window goes to OpenAI to find who you're replying to.»
- Launch at login (`SMAppService`).
- **Shortcut:** запись сочетания «Check text» (⌥⌘G по умолчанию); конфликт с системным — предупреждение под полем.
- Permissions: строка статуса Accessibility и Screen Recording с кнопкой «Open System Settings…». Своих переключателей для системных разрешений нет.

**Style**
- Custom instructions: многострочное поле, свободный текст.
- Per-app defaults: таблица «App · Context · Tone · Level» (заполняется сама из панели), удаление строки сбрасывает к общим умолчаниям Message · Neutral · Fluency.

**Dictionary**

Отдельная вкладка, потому что словарь растёт по ходу работы и может быть большим (сотни терминов), а Style — редко меняемые настройки.
- Поле поиска «Search N terms» сверху.
- Таблица `Term · Added`, сортировка по клику на заголовок, по умолчанию новые сверху. Двойной клик — исправить термин в листе «Edit Term».
- Под таблицей стандартные кнопки + / −: + открывает лист «Add Term» с полем, − и Delete удаляют выбранные строки. Термин, который уже есть в словаре в любом регистре, не добавляется: лист показывает «This term is already in the dictionary.»
- Import… / Export… — текстовый файл, по термину на строку; при импорте пустые строки и повторы пропускаются, рядом с кнопками подпись «Imported N terms.»
- Подсказка в нижней строке: «Add terms from the Proofreading panel: select a word and choose Never Change.»

**Prompts**
- **Что это:** тексты инструкций, которые приложение отправляет модели. Есть два вида:
  - **Pipeline** — целые промпты вызовов: Proofread (главная инструкция каждой проверки), Explain Changes (пишет причины правок), Classify Request (решает, вопрос твоё сообщение или просьба изменить текст), Read Context (кто в переписке и на что отвечаешь, со скриншота);
  - **фрагменты** — Text Types (Message, Email, Docs), Tones, Levels: короткие строки, которые подставляются в Proofread вместо `{type}`, `{tone}`, `{level}`, когда это значение выбрано в панели.
- Слева список по этим группам; изменённые отмечены «•», под списком легенда «• Modified».
- Справа под заголовком — что делает промпт («Main instructions for every check», «Inserted into Proofread as {type} when this type is selected in the panel»).
- Справа редактор выбранного промпта моноширинным шрифтом, под ним список доступных плейсхолдеров (`{type} {tone} {level} {language} {customInstructions}`), «Changes apply to the next check.» и кнопка «Restore Default».
- Сохраняется автоматически; встроенная версия не теряется.

**Account**
- «Signed in as name@email».
- Токены за сессию приложения (сумма `usage`).
- [Sign Out] — обычная (не основная) кнопка: revoke + удалить из Keychain, затем онбординг.
- Ссылка «Manage app usage limit» на страницу настроек ChatGPT.

## 6. Тексты интерфейса

Интерфейс на английском (как и пояснения модели); язык самого исправленного текста — любой (§2.3). Кнопки и пункты меню — title case («Try Again», «Copy Original»), сообщения и подсказки — sentence case с точкой. Короткие фразы, без восклицаний. Ошибки всегда говорят, что делать дальше.

## 7. Доступность

- Все контролы доступны с клавиатуры, включая Full Keyboard Access; порядок Tab: Context → карточки ленты (сводка, Copy) → поле диалога.
- У всех кнопок-значков (📷, ✕) есть accessibility label; лента — `log`-регион, новые карточки объявляются VoiceOver.
- Контраст текста ≥ 4.5:1 на подложках diff в обеих темах.
- Анимаций нет; появление текста потоком отключается при Reduce Motion (показываем целиком по готовности).
