### Следующий: пакет 16, доводка панели (0.2.1)

Спека: [05](specs/05-ui.md) §2.3a (Context), §2.7 (поле диалога).

**Проблема.** Новую версию сейчас запускают две кнопки в разных местах: Check/Recheck в секции Context и Send у поля диалога. Обе пересматривают текст, и непонятно, чем они отличаются. Check в строке Context смешивает ввод контекста с действием. В спеке кнопки стоят под полем контекста, но это проблему не решает.

**Решение** (согласовано с пользователем 2026-10-28):

- Context — только ввод: текст, картинки, 📷. Своих кнопок проверки в нём нет.
- Одна точка действия — внизу, у поля диалога. До первой проверки основная кнопка там — **Check**. После — **Send**; если контекст изменился, а поле диалога пустое, кнопка называется **Recheck** и перепроверяет с новым контекстом; если в поле есть сообщение, Send отправляет его вместе с новым контекстом.
- Смена типа, тона, уровня и языка в шапке по-прежнему перепроверяет сразу.

Шаги:

1. `git switch main && git pull`, затем `git switch -c feature/panel-polish`.
2. Записать решение в 05 §2.3a и §2.7 и в 03 S1 (Check внизу, а не в Context); снять пометку «Пересматривается» в 05 §2.3a. Раскладку Context без кнопок проверки показать пользователю до кода.
3. Core, сначала тесты в `ProofreadingSessionTests`: что отправляется при Check, Send и Recheck в каждом состоянии контекста.
4. App: раскладка по решению; Quick Look на миниатюре (пробел на выбранной и клик — крупный просмотр), чтобы отличить одинаковые картинки.
5. Готово, когда: сценарии проверены в приложении пользователем; `scripts/check` прошёл; в `CHANGELOG.md` под `[Unreleased]` описано, что получил пользователь; обновлены строка пакета 16, «Что работает», «Расхождения со спекой» и «Дальше» (следующий — пакет 10, его описание ниже); PR открыт. После слияния — `scripts/release 0.2.1`.

## Что работает

- Хоткей ⌥⌘G (настраивается) → текст из выделения или всего поля (Accessibility, ⌘C, скриншот окна — 02 C2) → панель рядом с полем с открытым Context → Check → потоковая проверка → карточка Version 1 с подсветкой и пояснениями.
- Шапка: тип, тон, уровень, язык результата; смена перепроверяет последнюю версию и запоминается для приложения.
- Context: поле над лентой, до первой проверки открыто; Check, потом Recheck; клик по строке раскрывает.
- Изображения в Context: 📷 снимает окно исходного приложения (перед первым запросом Screen Recording — строка пояснения), ⌘V вставляет картинку или файл изображения в любой раскладке и при любом фокусе в панели, файлы и картинки можно перетащить на панель. Миниатюры с ✕; после 10 изображений подпись предупреждает о скорости и расходе. Картинки уходят в первом сообщении Check и Recheck.
- Диалог: вопрос → ответ пузырём, просьба → новая карточка; кнопка Send.
- Карточка: Copy (основная у последней), список правок с причинами, отклонение правки локально.
- Ошибки: нет входа (кнопка входа и повтор), сеть, лимит, «Copy Original».
- Онбординг одним окном; Settings: General (модель, хоткей, меню, разрешения), Style (custom instructions), Account.
- Menu bar: Check Text…, Check Clipboard, модель, аккаунт, About, Settings, Quit.
