### Потом: пакеты 19–21, доводка промптов

Промпты доводим по одной категории за пакет, в порядке конвейера: чтение контекста → исправления и диалог → пояснения. Так видно, что именно помогло, а время на прогоны и оценку делится на итерации. Решено 2026-11-05.

Общее для трёх пакетов:

- Каждый вариант промпта — 2–3 прогона eval на каждой из трёх моделей (`gpt-6.1-sol`, `gpt-6-luna`, `gpt-6.1-terra`): разброс между прогонами больше разницы между моделями. Оценка — по тем же правилам ([evals/fix/README.md](../evals/fix/README.md), [evals/context/README.md](../evals/context/README.md)), сравнение — с таблицами 04 §5.
- Готово, когда кейсы, ради которых менялся промпт, проходят хотя бы в 2 прогонах из 3, а среди остальных нет новых провалов по сравнению с 04 §5.
- Итог пакета — таблица в 04 §5 по трём моделям: качество, время хода, токены. Из неё — какая модель для этой операции лучше по балансу цены, качества и скорости и что ставим по умолчанию.
- Если промпт меняется — релиз.

**Пакет 19 — чтение контекста.** На eval пакета 13 промпт уже проходит почти всё (04 §5): Luna 13/13 и 6/6, Terra — всё, но подробнее нужного и считает участников канала получателями, Sol хуже и медленнее. Прогнать `cyrano-eval context` на трёх моделях по 2–3 раза, поправить то, что повторяется, и подтвердить модель по умолчанию. Материал — синтетика и шесть настоящих кейсов, которые уже есть; новых живых скриншотов не ждём, новую ситуацию добавляем в синтетику (решено 2026-11-05).

**Пакет 20 — исправления и диалог** (`cyrano-eval fix`; промпты Fix и хода диалога):

- **Ответ на вопрос.** На вопрос о тексте модель иногда выдаёт текст вместо ответа (Sol, Terra). Гипотеза: вопрос идёт в тот же диалог, где инструкция велит выдавать только текст. Сначала проверить её, потом решать — отдельная инструкция или ответ вне диалога проверяющего; второе меняет `ProofreadingSession`.
- **Уточнение.** Новая версия меняет только то, чего уточнение касается; слова пользователя не заменяются словами из уточнения, при Errors Only — тем более (real-06, dialog-05).
- **Смысл важнее частотности:** `noted` → `noticed`, `as soon as possible` вместо «скоро», `today's PR 420`.
- **Имена.** Одно имя в тексте пишется одинаково (`Pria` / `Priya`). Словарь «Never change» — ещё и подсказка написания: похожее, но другое написание термина из словаря исправляется на словарное.
- **Тоны и формальность.** Тон в Fix — одна строка `Tone: friendly.`, и правила «не переписывай верные предложения» и «сохраняй слова автора» его перевешивают: Friendly не меняет «Check the docs before asking» ни у одной модели, Concise сокращает только у Luna. Описать тоны фрагментами. Формальность из Context (`formal`, руководитель) должна убирать `gonna`.

**Пакет 21 — пояснения и diff:**

- **Explain.** Необязательное (запятая перед `and` в перечислении) — `style`, а не правило. Модели пояснений сравниваем при одной модели исправлений: `cyrano-eval fix` получает отдельный выбор модели для Explain.
- **Diff.** Не склеивать правки через границу абзаца (04 §2).
- **Рекомендация пользователю.** По таблицам пакетов 19–21 — какую модель выбрать для каждой операции (чтение контекста, проверка и диалог, пояснения) и почему: качество, скорость, расход. В README, рядом с выбором моделей в Settings.

### Отложенные идеи

Пометки, чтобы не забыть, а не задачи.

- Кем собеседник приходится пользователю (руководитель, клиент), со скриншота часто не понять: в Teams нет должности. Отложено до следующих версий; пока Context этого не выводит, пользователь дописывает сам. Решено 2026-11-03.
- Сообщение, на которое пользователь отвечает, со скриншота целиком не получить: на экране часто только его часть. Пока его при необходимости вставляют в Context руками. Если описания ситуации (пакеты 13 и 19) не хватит, исследовать чтение беседы через Accessibility: Chrome отдаёт текст страниц, но у каждого приложения своё дерево элементов.
- Словарь — JSON (02 M11). Если понадобится хранить историю проверок, чтобы к ней можно было вернуться, — перейти на SQLite; решено 2026-10-29.

## Что работает

- Хоткей ⌥⌘G (настраивается) → текст из выделения или всего поля (Accessibility или ⌘C явного выделения, без ⌘A и без чтения со скриншота — 02 C2) → панель рядом с полем с открытым Context → Check у поля диалога → потоковая проверка → карточка Version 1 с подсветкой и пояснениями.
- Контекст со скриншота (02 C6): если текст взят из окна приложения, модель чтения контекста (по умолчанию `gpt-6-luna`) описывает по скриншоту окна беседу — с кем, на каком языке, о чём, формат (ответ, напоминание, новая тема), стиль, формальность — и заполняет Context строками, без копирования сообщений; язык беседы ставит в pop-up языка, если пользователь его не выбрал. Check ждёт до 20 с; статус чтения — у заголовка Context: секунды, Skip, «No conversation found», таймаут или ошибка с Try Again; Skip и ввод в Context прерывают вызов. Переключатель в Settings → General и в онбординге. Eval — `cyrano-eval context`: 13 синтетических окон в `evals/context/` и 6 настоящих в `evals/private/context/` (вне git), 13/13 и 6/6 на Luna (04 §5).
- Eval исправлений — `cyrano-eval fix evals/fix/cases.json [модель]`: 49 кейсов (9 настоящих), полный ход панели — Fix, Explain, диалог; отчёт оценивает агент, спорное — с пользователем. Sol 42/49, Luna 41/49, Terra 41/49 (04 §5).
- «Text to check» правится до первой проверки; если текст не забран (рабочий стол, Finder), панель открывается с пустой карточкой. Check Text… и Check Clipboard открывают ту же панель, отдельного окна нет.
- Панель высотой по содержимому до 70% высоты экрана, дальше прокручивается только лента; растёт вниз, верхний край на месте.
- Шапка: тип, тон, уровень, язык результата; смена перепроверяет последнюю версию. Тип, тон и уровень запоминаются для приложения, язык — нет: панель открывается с «Auto». Запомненное видно в Settings → Style → Per-app defaults, удаление строки возвращает Message · Neutral · Fluency.
- Подсказки TipKit в панели: Context, 📷, поле диалога — по одной, пока их не закроют или не выполнят.
- Context — только ввод: поле над лентой, до первой проверки открыто, при запросе сворачивается; клик по строке раскрывает.
- Одна кнопка у поля диалога: Check до первой проверки и когда контекст изменился, а поле пустое (перепроверка); иначе Send — сообщение уходит вместе с текущим контекстом. Поле диалога появляется после первой проверки. Индикатор — одно число токенов.
- Изображения в Context: 📷 снимает окно исходного приложения (перед первым запросом Screen Recording — строка пояснения), ⌘V вставляет картинку или файл изображения в любой раскладке и при любом фокусе в панели, файлы и картинки можно перетащить на панель. Миниатюры с ✕; после 10 изображений подпись предупреждает о скорости и расходе. Клик или пробел на миниатюре — Quick Look. Картинки уходят в первом сообщении каждого запроса Fix.
- Диалог: вопрос → ответ пузырём, просьба → новая карточка.
- Карточка: Copy (основная у последней), список правок с причинами, отклонение правки локально.
- Словарь «Never change» (02 M11): правый клик по выделению в карточке версии или в «Text to check» — Never Change “…” или Remove “…” from Dictionary (в «Text to check» — над пунктами текстового поля: Cut, Copy, Paste, орфография); правый клик по строке изменения последней карточки — Never Change для каждого изменённого слова: правка отклоняется, слово добавляется одним действием. Строка статуса «“…” added to Dictionary.» с Undo. Найденные в тексте термины идут в первом сообщении Fix строкой `Keep these words exactly as written: …` со следующего запроса; термин из «Text to check» — уже с первой проверки. Файл — `~/Library/Application Support/Cyrano/dictionary.json`.
- Ошибки: нет входа (кнопка входа и повтор), сеть, лимит, «Copy Original».
- Модели: `gpt-6.1-sol`, `gpt-6.1-terra`, `gpt-6-luna`; выбор отдельно для чтения контекста (по умолчанию Luna), проверки и диалога (Sol), пояснений (Sol). Классификатор идёт на модель проверки.
- Онбординг одним окном: вход, Accessibility, контекст из окна (переключатель и Screen Recording), хоткей. Settings: General (меню, Launch at login, чтение контекста, модели, хоткей, разрешения), Style (custom instructions, per-app defaults), Dictionary (поиск, добавление, правка двойным кликом, удаление, импорт и экспорт), Account.
- Menu bar: Check Text…, Check Clipboard, аккаунт, About, Settings, Quit. Своя иконка приложения.
