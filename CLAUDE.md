# Cyrano

Нативное приложение macOS для проверки коротких текстов через модели по подписке ChatGPT. Перед работой прочитай [docs/README.md](docs/README.md): там спецификация и порядок чтения.

- `Packages/CyranoCore/` — логика (клиент OpenAI, авторизация, промпты, diff, словарь, настройки), тестируется `swift test`.
- `App/` — только UI, AX, хоткеи, окна. Логику, которую можно проверить тестом, держи в CyranoCore.
- `evals/` — набор примеров и раннер для проверки промптов.

Документация на русском, код и комментарии в коде на английском. Отступ 2 пробела.

## Качество кода

Подробности и пороги: [docs/quality.md](docs/quality.md).

**Итерация не закончена, пока `scripts/check` не прошёл.** Запускай его перед тем, как сказать, что работа готова, и в итоговом сообщении скажи, что он показал. Форматирование чини `scripts/check --fix`.

Когда проверка падает:

- **Сложность или размер** — раздели функцию или тип по смыслу: вынеси шаг, введи тип для группы параметров, вынеси подвью. Не дроби механически ради цифры.
- **Дубликат** — вынеси общее в одно место. Не копируй функцию с правками.
- **Неиспользуемый код** — удали. Не держи код «на будущее».
- **Предупреждение компилятора** — исправь причину.

Нельзя:

- ослаблять пороги и правила в `.swiftlint.yml`, `.jscpd.json`, `.periphery.yml`, `Package.swift` без согласия пользователя;
- подавлять правило без причины. Допустимо только точечно: `// swiftlint:disable:next <rule> - <причина>`, и упомяни это в отчёте;
- глушить компилятор: `!`, `try!`, `as!`, `@unchecked Sendable`, `nonisolated(unsafe)`, `@preconcurrency` — только с комментарием, почему это безопасно.

Как писать:

- Сначала тест на поведение, потом код. Тест вызывает код так, как его вызывает пользователь, и проверяет то, что тот увидит.
- Данные извне (ответы API, JSON, AX) разбирай один раз на границе в типы; внутри им доверяй.
- Недопустимые состояния делай невыразимыми: `enum` с associated values вместо набора опциональных полей и флагов.
- Одно решение — в одном месте. Сначала убери лишнее, потом добавляй.
