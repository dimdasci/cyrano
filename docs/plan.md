## Preview 0.1: что работает

- Хоткей ⌥⌘G (настраивается) → текст из выделения или всего поля → панель рядом с полем с открытым Context → Check (⌘R) → потоковая проверка → карточка Version 1 с подсветкой и пояснениями.
- Шапка: тип, тон, уровень, язык результата; смена перепроверяет последнюю версию и запоминается для приложения.
- Context: поле над лентой, до первой проверки открыто; Check, потом Recheck (⌘R); ⌘K раскрывает.
- Диалог: вопрос → ответ пузырём, просьба → новая карточка; ⌘↩ отправляет.
- Карточка: Copy (⇧⌘C у последней), список правок с причинами, отклонение правки локально.
- Ошибки: нет входа (кнопка входа и повтор), сеть, лимит, «Copy Original».
- Menu bar: Check Text…, Check Clipboard, модель, аккаунт, About, Settings, Quit.

## Отступления preview от спеки

- Онбординг — один экран с тремя секциями вместо пошагового мастера.
- Сочетания внутри панели фиксированные; ⌘C для последней версии не назначен, чтобы не перехватывать копирование в полях.
- Поле диалога фиксированной высоты (↩ — перенос строки), панель фиксированного размера 520×560, растягивается вручную.
- Recheck отправляет в диалог служебную реплику ([04](specs/04-prompts.md) §4.3), чтобы пожелания из диалога сохранялись.
- Иконка приложения — системная по умолчанию.
- Insert убран: результат только копируется (02 C3). Вайрфреймы в `docs/wireframes/` ещё показывают Insert.
- Захват идёт по цепочке: фокус через Accessibility (с включением веб-доступности Chrome/Electron) → поиск поля с фокусом внутри страницы → ⌘C → ⌘A ⌘C → скриншот окна, из которого модель читает черновик. Текст со скриншота можно только копировать. Screen Recording нужен только для последнего шага; разрешение показано в Settings → General рядом с Accessibility.
- Подпись — локальным самоподписанным сертификатом (`scripts/make-signing-identity`); без него ad-hoc, и разрешение Accessibility сбрасывается при каждой пересборке.
