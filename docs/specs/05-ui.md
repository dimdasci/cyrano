# 05. UI

Статус: **черновик, сверен с Apple HIG** 2026-10-27 (§8). Сценарии — [03](03-mvp-scope.md), технические решения — [02](02-tech-decisions.md), wireframes — [../wireframes](../wireframes/README.md).

## Принципы

- **Функциональность, а не эффекты.** Никаких анимаций, кроме системных. Никаких всплывающих подсказок поверх чужих приложений.
- **Клавиатура прежде всего.** Всё основное делается без мыши.
- **Чужое окно не теряет фокус ввода, пока не нужно.** Панель — `NSPanel` (`.nonactivatingPanel`). Фокус она забирает только при клике в поле диалога или Context.
- **Системный вид.** SwiftUI + стандартные контролы, семантические системные цвета и шрифты, светлая и тёмная темы.
- **Цвет — не единственный носитель смысла.** Каждое цветовое различие продублировано формой: зачёркивание, подчёркивание, значок, заголовок группы.
- **Ориентир — Writing Tools в macOS.** Системная функция Apple решает похожую задачу (proofread поверх любого приложения, поле «Describe your change»), поэтому в спорных местах повторяем её поведение.
- **Текст пользователя не теряется.** При любой ошибке исходник остаётся доступен для копирования.

## 1. Онбординг

Три шага в одном окне, кнопки Back / Continue.

```
┌─ Cyrano ───────────────────────────────────────────┐
│                                                    │
│  1 ● Sign in    2 ○ Accessibility    3 ○ Shortcut  │
│                                                    │
│  Cyrano uses your ChatGPT Plus or Pro plan         │
│  to check your messages.                           │
│                                                    │
│        [  Continue with ChatGPT  ]                 │
│                                                    │
│  Your text is sent to OpenAI only when you run     │
│  a check. It is not stored (store: false).         │
│                                                    │
└────────────────────────────────────────────────────┘
```

1. **Sign in.** Кнопка «Continue with ChatGPT» по гайдлайнам OpenAI → системный браузер. Пока ждём колбэк: «Waiting for the browser…» [Cancel]. Удачный вход: «Signed in as name@…», затем автоматически шаг 2. Ошибки:
   - отказ в браузере → «Sign-in was cancelled.» [Try Again];
   - нет `chatgpt.tokens.use.direct` → «Your plan doesn't allow apps to use it. Plus or Pro is required.»;
   - сеть / таймаут 5 мин → «Couldn't reach OpenAI.» [Try Again].
2. **Accessibility.** Одно предложение о том, зачем: «Cyrano reads the text in the field you're typing in, so you don't have to copy it.» Кнопка «Open System Settings…». Статус обновляется сам (опрос `AXIsProcessTrusted` раз в секунду) → «✓ Granted». Кнопка «Skip»: без разрешения работает режим через буфер обмена.
3. **Shortcut.** Поле записи хоткея (по умолчанию ⌥⌘G), подсказка «Select text or put the cursor in a text field, then press the shortcut.» и переключатель «Show in menu bar» (включён). Кнопка «Done». Остальное объясняем контекстными подсказками в самой панели при первом использовании (TipKit): Context, 📷, диалог.

Screen Recording в онбординге не спрашиваем — только при первом нажатии 📷.

## 2. Панель проверки

### 2.1 Положение и размер

- Ширина 520 pt, высота по содержимому, максимум 70% высоты экрана, дальше прокрутка.
- Позиция: под полем ввода (bounds из AX), если поле видно и под ним хватает места; иначе над полем; иначе по центру экрана, где курсор.
- У панели стандартная строка заголовка с коротким заголовком-существительным **«Proofreading»** и кнопкой закрытия; кнопок свернуть/развернуть нет. Перетаскивается за заголовок. Позиция не запоминается.
- Закрывается по Esc и по кнопке ✕. При клике в другое место **не закрывается** — можно переключиться в чат, скопировать контекст и вернуться.

### 2.2 Макет

│ ▸ Context  Ravi: Hi Alex, when you were off last week, I… ▭ ▭ 📷│  ← контекст: одна строка

│ │ ▸ 5 fixes · 1 style suggestion                    [Copy]  │ │

### 2.3 Заголовок

- **Источник:** имя приложения, из которого взят текст («Slack»). Для окна ручной проверки — «Manual».
- **Тип контекста:** Message / Email / Docs. **Тон:** Neutral / Casual / Friendly / Professional / Concise. **Уровень:** Errors only / Fluency / Rewrite. Это стандартные pop-up buttons (SwiftUI `Picker` со стилем `.menu`): название значения и двойной шеврон в квадрате акцентного цвета. Смена любого значения перепроверяет последнюю версию с новыми настройками и добавляет в ленту новую карточку. Значения запоминаются для приложения (bundle id).
- **Язык результата** — pop-up справа в шапке со значком глобуса: «Same as Text (English detected)» (по умолчанию, в кнопке — «Auto»), English (US), English (UK), Russian, German, Spanish, «More Languages…». Выбор перепроверяет последнюю версию и добавляет новую карточку; если язык отличается от языка текста, модель переводит. Значение запоминается для приложения вместе с типом и тоном.
- ✕ закрывает панель.

### 2.3a Контекст

Контекст — то, на что пользователь отвечает, — стоит **над** текстом: так панель читается сверху вниз, как переписка. Секция занимает одну строку и не раздувает панель.

- **Свёрнуто, есть содержимое:** `▸ Context` + первая строка текста контекста (обрезается многоточием) + миниатюры изображений 30×22 + кнопка 📷. Клик по строке или ⌘K раскрывает.
- **До первой проверки:** раскрыто, курсор в поле контекста, справа основная кнопка **Check** (⌘R); в ленте карточка «Text to check» с забранным текстом. Поле диалога недоступно, смена типа, тона и уровня проверку не запускает. После Check секция сворачивается, кнопка становится «Recheck».
- **Свёрнуто, пусто:** `▸ Context` + приглушённая подсказка «Add what you're replying to» + 📷.
- **Раскрыто:** поле на 3 строки (растягивается до 8, потом прокрутка), под ним миниатюры 56×38 с ✕, кнопка 📷, подпись «or paste ⌘V / drop images · 2 images» и кнопка «Recheck». Пробел на выбранной миниатюре — Quick Look, крупный просмотр. Текст редактируется прямо в поле: можно дописать руками что угодно.
- **Изображения:** 📷 снимает активное окно исходного приложения; ещё можно вставить ⌘V или перетащить файл на панель. Жёсткого предела нет; после 10 изображений подпись предупреждает, что проверка станет медленнее и дороже. Первое нажатие 📷 — системный запрос Screen Recording, перед ним одна строка: «To see the conversation you're replying to, Cyrano needs to capture this window once.» Для вставки и перетаскивания разрешение не нужно.
- Изменение контекста само проверку не перезапускает — кнопка «Recheck» (⌘R). Добавление или удаление изображения — тоже через Recheck.
- Свернуть обратно — клик по `▾ Context` или Esc, когда фокус в поле контекста.

### 2.4 Лента: чат с карточками версий

Панель — это чат. Каждый вариант текста от модели — **карточка**, сообщения пользователя и ответы на вопросы — пузыри между карточками. Отдельной навигации по версиям нет: история — это прокрутка ленты.

- **Порядок:** Version 1 (первая проверка) → сообщение → Version 2 → … Новое появляется внизу, лента прокручивается к нему. Лента растёт вместе с панелью до 70% высоты экрана, дальше прокручивается только она; заголовок, Context и поле ввода остаются на месте.
- **Сообщение пользователя** — пузырь справа (accent color), показывается целиком, переносится по ширине. **Ответ на вопрос** — пузырь слева, без новой карточки.
- **Своя версия** («check my version: …») — сообщение целиком, а исправленный вариант — следующая карточка.

**Карточка версии**
- Шапка: «Version N».
- **Действие — внутри карточки**, в строке со сводкой справа: **Copy**. Так всегда видно, какой именно вариант копируется. У последней карточки Copy — основная кнопка (accent color, ⇧⌘C), у предыдущих — обычная, без сочетания. Copy кладёт вариант карточки в буфер обмена, панель остаётся открытой; вставляет пользователь сам (02 C3).
- Текст с diff относительно предыдущей карточки (у Version 1 — относительно исходника), шрифт системный 14 pt, текст можно выделять и копировать. Удалённое зачёркнуто и приглушено (`secondaryLabelColor`); добавленное — сплошное подчёркивание и подложка `systemGreen` 20%; правки `style` — пунктирное подчёркивание и подложка `systemBlue` 15%. Цвет дублируется типом линии.
- Под текстом одна строка-сводка «▸ 5 fixes · 1 style suggestion» (или «▸ 1 change», «✓ No changes needed»). Клик раскрывает список изменений.
- Список изменений: значок (● ошибка, ◇ стиль), справа в столбик `было → стало` (моноширинный, длинные правки переносятся) и причина; справа ✕ «отклонить». Отклонение создаёт новую карточку локально, без вызова модели. Пока Explain не пришёл, сводка — «Explaining…»; если упал — правки без причин.
- Карточку нельзя редактировать: изменения просим сообщением.
- VoiceOver читает правку как «noted, replaced with noticed, error» / «… style suggestion»; карточка объявляется как «Version 2, 1 change».

**Словарь из карточки**
- Выделить слово или фразу → контекстное меню (правый клик или ⌃-клик) → **Never Change “…”**. Для слова из словаря меню показывает «Remove “…” from Dictionary». Внизу панели строка «“Bitbucket” added to Dictionary.» с Undo. Учитывается со следующей проверки.
- Тот же пункт в контекстном меню строки изменения («Never Change “k8s”»): отклоняет правку и добавляет термин одним действием.

### 2.7 Нижняя часть

Поле диалога на всю ширину, под ним одна строка статуса: индикатор токенов и короткие сообщения («“Bitbucket” added to Dictionary.» с Undo, «Copied.»). Кнопок здесь нет: Copy живёт в карточках. Сочетания клавиш не пишем внутри кнопок, они в подсказке и в меню. Подписи и статус не переносятся — длинный статус обрезается многоточием, полный текст в подсказке.

- **Индикатор токенов** `1.2k tokens`: сумма `usage` за диалог. По наведению — разбивка по вызовам (Fix / Explain / Intent). Если лимит подписки исчерпан — красный «Plan limit reached».
- **Поле диалога** — многострочное: растёт от 1 до 6 строк по мере ввода, дальше прокручивается внутри. ↩ — перенос строки. Отправка — круглая кнопка **Send** (стрелка вверх) справа внутри поля или ⌘↩. Пока поле пустое, Send неактивна. Плейсхолдер «Ask or tell what to change… (any language)». Новое сообщение применяется к последней версии.
- **⇧⌘C (Copy)** работает из любого места панели и относится к последней карточке; ⌘C остаётся обычным копированием выделенного.

### 2.8 Состояния панели

| Состояние | Что видно |
|---|---|
| Захват | «Reading text…» (обычно мгновенно, не мигает, если < 150 мс) |
| Пусто | «Nothing to check. Select text or put the cursor in a text field.» + кнопка «Check clipboard» |
| Проверка | исходный текст приглушён, сверху тонкая полоса прогресса; текст версии появляется потоком |
| Результат | см. макет |
| Ход диалога | поле ввода заблокировано, в ленте «…» |
| Ошибка сети / таймаут | «Couldn't reach OpenAI.» [Try Again] [Copy Original] |
| Лимит | «Your ChatGPT plan limit for this app is reached.» [Copy Original]; ссылка на настройки лимита |
| Не вошёл / токен отозван | «Sign in to ChatGPT to check text.» [Continue with ChatGPT] |
| Нет Accessibility | панель работает с буфером обмена; в заголовке значок ⚠︎ с подсказкой «Grant Accessibility to read text directly» |

### 2.9 Клавиатура

Все сочетания — **умолчания**, каждое меняется в Settings → General → Keyboard Shortcuts (там же сброс к умолчанию).

| Действие | По умолчанию | Где работает |
|---|---|---|
| Check text — открыть панель для текущего поля | ⌥⌘G | глобально |
| Send message | ⌘↩ | поле диалога |
| Copy latest version | ⇧⌘C | панель |
| Edit context | ⌘K | панель |
| Recheck | ⌘R | панель |

Не настраиваются (системные): ↩ — перенос строки в поле диалога, Esc — закрыть панель (если фокус в поле — сначала убрать фокус), Tab — переход между элементами, ⌃-клик / правый клик по выделению — контекстное меню с Never Change.

## 3. Окно ручной проверки

Обычное окно 600×500 с полем «Paste text to check» сверху и той же панелью ниже. Кнопка «Check» (⌘↩ в поле ввода). Нужно, когда захват не сработал или текст пришёл не из поля ввода.

## 4. Меню в строке меню

Иконка — SF Symbol `text.badge.checkmark` (шаблонная, 24 pt строка меню). По клику — меню, не popover. Показ иконки — выбор пользователя («Show in menu bar» в онбординге и General). Если иконка скрыта, повторный запуск приложения из Finder или Spotlight открывает Settings — это единственная точка входа кроме хоткея.

```
Check Text…                 ⌥⌘G
Check Clipboard
─────────────────────────────
Model: gpt-6.1-sol            ▸   (sol / luna)
Signed in as name@…
─────────────────────────────
About Cyrano
Settings…                    ⌘,
Quit Cyrano                 ⌘Q
```

Если не вошёл — вместо строки аккаунта «Sign In with ChatGPT…». Если нет Accessibility — пункт «Grant Accessibility…». Многоточие только у пунктов, которые открывают окно или требуют ввода.

## 5. Settings

Окно со стандартной неизменяемой панелью инструментов из пяти вкладок — General, Style, Dictionary, Prompts, Account (значок + подпись); содержимое — SwiftUI `Form` со стилем `.grouped`: скруглённые секции, подпись слева, контрол справа, строки 40–44 pt, переключатели — `Toggle` в виде switch, выпадающие списки — стандартные pop-up buttons регулярного размера; заголовок окна — имя активной вкладки; открывается последняя использованная вкладка; кнопки свернуть/развернуть неактивны. Настроек минимум: всё, что относится к текущей проверке (тип, тон, уровень, контекст), меняется в самой панели.

**General**
- Model: `gpt-6.1-sol` — Best quality · `gpt-6-luna` — Faster.
- Show in menu bar.
- Launch at login (`SMAppService`).
- **Keyboard Shortcuts:** список «действие · где работает · сочетание · ↺ сброс». Клик по полю — запись нового сочетания; конфликт с системным или уже назначенным — предупреждение под полем.
- Permissions: строка статуса Accessibility и Screen Recording с кнопкой «Open System Settings…». Своих переключателей для системных разрешений нет.

**Style**
- Custom instructions: многострочное поле, свободный текст.
- Per-app defaults: таблица «App · Context · Tone · Level» (заполняется сама из панели), удаление строки сбрасывает к общим умолчаниям Message · Neutral · Fluency.

**Dictionary**

Отдельная вкладка, потому что словарь растёт по ходу работы и может быть большим (сотни терминов), а Style — редко меняемые настройки.
- Поле поиска «Search N terms» сверху.
- Таблица `Term · Added`, сортировка по клику на заголовок, по умолчанию новые сверху. Двойной клик — исправить термин.
- Под таблицей стандартные кнопки + / −; Delete удаляет выбранные строки.
- Import… / Export… — текстовый файл, по термину на строку.
- Подсказка в нижней строке: «Add terms from the Proofreading panel: select a word and choose Never Change.»

**Prompts**
- **Что это:** тексты инструкций, которые приложение отправляет модели. Есть два вида:
  - **Pipeline** — целые промпты вызовов: Proofread (главная инструкция каждой проверки), Explain Changes (пишет причины правок), Classify Request (решает, вопрос твоё сообщение или просьба изменить текст);
  - **фрагменты** — Text Types (Message, Email, Docs), Tones, Levels: короткие строки, которые подставляются в Proofread вместо `{type}`, `{tone}`, `{level}`, когда это значение выбрано в панели.
- Слева список по этим группам; изменённые отмечены «•», под списком легенда «• Modified».
- Справа под заголовком — что делает промпт («Main instructions for every check», «Inserted into Proofread as {type} when this type is selected in the panel»).
- Справа редактор выбранного промпта моноширинным шрифтом, под ним список доступных плейсхолдеров (`{type} {tone} {level} {language} {customInstructions}`), «Changes apply to the next check.» и кнопка «Restore Default».
- Сохраняется автоматически; встроенная версия не теряется.

**Account**
- «Signed in as name@email».
- Токены за сессию приложения (сумма `usage`).
- [Sign Out] — обычная (не основная) кнопка: revoke + удалить из Keychain, затем онбординг.
- Ссылка «Manage app usage limit» на страницу настроек ChatGPT.

## 6. Тексты интерфейса

Интерфейс на английском (как и пояснения модели); язык самого исправленного текста — любой (§2.3). Кнопки и пункты меню — title case («Try Again», «Copy Original»), сообщения и подсказки — sentence case с точкой. Короткие фразы, без восклицаний. Ошибки всегда говорят, что делать дальше.

## 7. Доступность

- Все контролы доступны с клавиатуры, включая Full Keyboard Access; порядок Tab: Context → карточки ленты (сводка, Copy) → поле диалога.
- У всех кнопок-значков (📷, ✕) есть accessibility label; лента — `log`-регион, новые карточки объявляются VoiceOver.
- Контраст текста ≥ 4.5:1 на подложках diff в обеих темах.
- Анимаций нет; появление текста потоком отключается при Reduce Motion (показываем целиком по готовности).
